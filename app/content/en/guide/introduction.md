# Introduction

ArixPHP is a PHP framework for building websites that are at home on traditional hosting.

Build content-driven websites with PHP, HTML, CSS, and JavaScript. Arix renders HTML on the server and provides routes, views, components, Markdown support, and translation catalogs. Add frontend interactivity where you need it.

The Arix CLI creates, serves, tests, and maintains projects on your development computer. The application includes the framework code it needs at runtime, so you do not install Composer or Node or run a frontend build on the deployment server. The server still needs a supported PHP runtime and web-server configuration; see [deployment](deployment).
