# Introducción {#introduction}

ArixPHP es un framework PHP para crear sitios web que funcionan en alojamiento tradicional.

Crea sitios centrados en el contenido con PHP, HTML, CSS y JavaScript. Arix genera HTML en el servidor y proporciona rutas, vistas, componentes, soporte para Markdown y catálogos de traducción. Añade interactividad frontend donde la necesites.

La CLI de Arix crea, sirve, prueba y mantiene proyectos en tu computadora. La aplicación incluye el código del framework que necesita en ejecución, por lo que no debes instalar Composer ni Node ni compilar el frontend en el servidor de despliegue. El servidor sigue necesitando un entorno PHP y una configuración web compatibles; consulta [despliegue](deployment).
